# big-brother

`big-brother` is compliance-support tooling for image moderation workflows on
operator-controlled infrastructure.

Use it as a software component for local hash matching, model-based review
triage, audit records, and operator review workflows. Do not treat it as legal
advice or as a substitute for counsel, agency guidance, or official regulator
technology requirements.

## Initial deployment target

- Linux server with an NVIDIA GPU.
- Docker Compose.
- FastAPI application service.
- NVIDIA Triton model serving.
- Synthetic fixtures only.
